## 🚀 COMO USAR (SIMPLES)

### Opção 1: Interface Visual (Recomendado)

```bash
npm run dev
```

Depois abra: **http://localhost:3000/admin/generate**

Clique em: **"🎨 Gerar Todas as Imagens"**

### Opção 2: Linha de Comando

```bash
# Terminal 1
npm run dev

# Terminal 2
npm run generate:images
```
