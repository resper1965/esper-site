# Changelog

Todas as mudanças notáveis neste projeto serão documentadas aqui.

O formato segue [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/),
e o versionamento segue [Semantic Versioning](https://semver.org/lang/pt-BR/).

## [1.0.0] - 2025-12-25

### Added

- Blog com geração automática de posts usando Claude AI
- Sistema de coleta de fontes (CISA, OWASP, Krebs, Dark Reading, ANPD)
- Dashboard de analytics
- Cron job diário para geração automática
- Design greyscale responsivo
- Internacionalização (PT-BR/EN)
- SEO otimizado com OG images dinâmicas

### Documentation

- CONTRIBUTING.md com guidelines de contribuição
- CODE_OF_CONDUCT.md (Contributor Covenant)
- SECURITY.md com política de disclosure
- Documentação técnica em `/docs`

### Infrastructure

- CI/CD com GitHub Actions
- Deploy automático na Vercel
- Conventional Commits com commitlint
